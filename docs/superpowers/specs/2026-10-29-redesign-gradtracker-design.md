# StudyHub 리디자인 + 대학원 지원요건 트래커 설계 (2026-10-29)

이 문서는 `2026-10-29-studyhub-design.md`(1단계 설계)의 **§9 디자인 방향을 대체**하고, **§6.8 대학원 지원 트래커를 구체화**한다. 나머지 1단계 설계(데이터 모델, 학점 계산 규칙, XP 규칙 등)는 그대로 유효하다. 충돌하면 이 문서가 이긴다.

시안: `.superpowers/brainstorm/1503-1793242537/content/paper-pages-v2.html` (사용자 승인본). 그 이전 파일(`mascot.html`, `style-direction.html`, `paper-pages.html`)은 기각된 안이라 참고만.

## 1. 의도와 이유

1단계를 써 본 사용자의 평: "디자인이 말이 안 된다." 따뜻한 파스텔 + 둥근 카드 + 그림자 조합이 촌스럽고 AI 템플릿처럼 보인다. 사용자가 원하는 것은 **투두메이트(Todo Mate) 같은 담담한 흰 화면** — 글자와 선으로만 구성되고, 색은 카테고리 라벨과 체크박스에만 들어가는 앱.

동시에 북미 대학원 지원 준비 중이라 **여러 학교의 지원 요건을 한 표로** 보고 싶다. 학교마다 GRE 요구 여부, TOEFL 최소 점수, 추천서 수, 마감일이 달라서 지금은 머릿속·메모에 흩어져 있다.

## 2. 목표 / 비목표 / 안티목표

**목표**
- 모든 화면을 "페이퍼" 스타일로 다시 입힌다 (§4). 기능은 유지.
- 홈을 투두메이트 구조로 재배치한다 (§5.1). 할 일에 **카테고리**가 생긴다.
- 대학원 지원요건 트래커를 추가한다: 웹은 표, 폰은 카드, 웹에서 표/카드 전환 (§5.4).
- 웹(노트북)에서 먼저 완성. 모바일은 깨지지 않을 정도면 됨.

**비목표**
- 논문·연구 보드 (2단계), 일반 마감 D-day 관리(§6.7), 이번 학기 과목 점수 — 이번엔 안 함.
- 마스코트/캐릭터/일러스트 — **넣지 않는다** (사용자가 명시적으로 뺌).
- 애니메이션 추가. 기존 레벨업 토스트와 confetti는 유지하되 새로 만들지 않음.

**안티목표 (이러면 실패)**
- 둥근 모서리, 그림자, 그라데이션, 큰 파스텔 면이 돌아오는 것.
- 이모지를 아이콘 대신 쓰는 것.
- 할 일 카테고리 때문에 할 일 추가가 한 번 더 복잡해지는 것 (추가는 여전히 한 줄 입력 + Enter).

## 3. 제약

- 스택 변경 없음: Vite + React 19 + TS + Tailwind v4(`@theme` 토큰) + Firebase + react-router + Recharts + vite-plugin-pwa + vitest.
- 기존 Firestore 데이터와 호환: 기존 `todos` 문서에 카테고리가 없어도 정상 표시(§6).
- 한국어 기본, 영어 번역 키는 같이 추가 (`ko.json`/`en.json`).
- 터치 타깃 44px 유지. 입력 폰트 16px 유지(iOS 확대 방지).
- 배포는 지금처럼 `vercel --prod --yes`.

## 4. 디자인 시스템 "페이퍼"

### 4.1 원칙
- **흰 바탕, 검정 글자, 선 하나로 구분.** 면(배경색 있는 카드)을 거의 쓰지 않는다. 섹션 구분은 1px 선 또는 여백.
- **색은 의미가 있을 때만.** 카테고리 라벨·체크박스·일정 막대·상태 태그. 장식용 색 없음.
- **각지게.** 모서리 반경 3–4px. 체크박스는 네모. 진행 막대는 직선(0px).
- **그림자 없음.** 모달과 드롭다운만 아주 옅은 그림자 허용 (`0 2px 8px rgba(0,0,0,.08)`).
- 아이콘: 1.8px 선 아이콘, 기존 `icons.tsx` 유지하되 굵기 통일.

### 4.2 토큰 (`src/index.css` `@theme` 교체)
라이트:
```
--color-bg: #ffffff        --color-surface: #ffffff      --color-surface-2: #f5f5f5
--color-ink: #111111       --color-ink-muted: #8a8a8a    --color-ink-faint: #b5b5b5
--color-line: #ececec      --color-line-strong: #e3e3e3
--color-primary: #111111   --color-on-primary: #ffffff
--color-danger: #d86a8b    --color-success: #3da874      --color-warn: #c28a1b
```
파스텔 팔레트 (카테고리·일정·상태용, 각각 `fill`/`text` 한 쌍):
```
sky    fill #a9c6f0  text #7fa6e8
mint   fill #a3dcc0  text #6fbf9a
pink   fill #f3b8cb  text #e08ba8
butter fill #f6dc9a  text #d1a93c
lilac  fill #cdbff2  text #a08bdc
peach  fill #f7c6a9  text #e39a6a
```
반경: `--radius-card: 4px`, `--radius-pill: 3px` (이름은 유지해 교체 범위를 줄임). `--shadow-soft`는 모달용으로만 남김.

다크 (시스템 따라감, 기존 토글 유지): `bg #111111`, `surface #161616`, `surface-2 #222222`, `ink #f2f2f2`, `ink-muted #9a9a9a`, `ink-faint #5a5a5a`, `line #262626`, `line-strong #333333`, `primary #f2f2f2`, `on-primary #111111`. 파스텔 `fill`은 그대로, `text`는 그대로 (어두운 바탕에서 충분히 보임).

### 4.3 타이포
- Pretendard(기존). 본문 14px / 보조 12–13px / 페이지 제목 22px 700 / 큰 숫자 30px 800 letter-spacing -1px.
- 숫자는 `tabular-nums`.
- 보조 텍스트는 `ink-muted`, 비활성/취소선은 `ink-faint`.

### 4.4 공통 컴포넌트 (`src/components/ui`) 바뀌는 점
- `Button`: primary = 검정 바탕 흰 글자, secondary = 1px `line-strong` 테두리, danger = 글자만 `danger`. 반경 4px. 높이 40px(모바일 44px).
- `Input`: 아래쪽 1px 선만 있는 스타일 대신 **1px 전체 테두리 + 4px 반경** (폼에서 구분이 필요). 포커스는 테두리 `ink`.
- `Chip`/필터: 1px 테두리 pill(3px), 선택 시 검정 바탕.
- `Segmented`(설정에 있음): 표/카드 전환에도 재사용. 1px 테두리 상자 안에 선택 항목만 검정.
- `Modal`: 흰 바탕, 4px 반경, 옅은 그림자.
- 상태 태그 `Tag`: 11px 600, 3px 반경, 배경은 색의 12% 틴트 + 글자색. 종류: `ok`(success) / `warn`(warn) / `bad`(danger) / `none`(ink-muted on surface-2).

### 4.5 레이아웃
- 데스크톱(≥768px): 좌측 사이드바 190px, 오른쪽 1px 선. 본문 패딩 26–30px, 최대 폭 1100px.
- 모바일: 하단 탭바 5개 — **홈 · 학점 · 시간표 · 대학원 · 더보기**. 더보기 안에 논문 · 연구 · 설정.
- 사이드바 메뉴 순서: 홈 · 학점 · 시간표 · 논문 · 연구 · 대학원, 맨 아래 설정. 선택 항목은 `surface-2` 배경 4px 반경.
- 페이지 머리: 왼쪽 제목(22px) + 한 줄 보조문, 오른쪽 주 동작 버튼. (시안의 "top" 행)

## 5. 화면

### 5.1 홈 (투두메이트 구조)
위에서 아래로:
1. **머리**: "10월 29일 수요일" + 보조문 "안녕, {이름}. 오늘 할 일 7개 중 3개 끝냈어요." 오른쪽에 pill "Lv.4 · 310 / 450 XP".
2. **주간 띠**: 월~일 7칸, 오늘은 검정 바탕 흰 글자, 주말은 `ink-faint`. 양 끝에 ‹ › 로 주 단위 이동, 오늘이 보이지 않는 주에서는 "오늘" 작은 버튼으로 복귀. 칸을 누르면 **선택한 날짜**가 바뀐다(오늘이 아닌 날도 추가·체크 가능).
   선택한 날짜를 따라가는 것: 머리의 날짜와 보조문("10월 30일 할 일 2개 중 0개"), 할 일 목록과 "n / m" 수, 완료율 숫자·막대. **오늘에 고정**되는 것: 오늘 일정, 마감 D-day, 지난 할 일 배너, 100% confetti(오늘 목록이 100%일 때만).
3. **2열** (데스크톱 1.25fr : 0.75fr, 모바일은 세로로):
   - 왼쪽 **할 일**: 제목 "오늘 할 일  3 / 7". 카테고리별로 묶음 — 카테고리 이름은 12px 700, 그 카테고리의 `text` 색. 항목은 17px 네모 체크박스(미완료: 1.5px 카테고리 `fill` 테두리, 완료: `fill` 채움 + 흰 체크) + 14px 제목. 완료는 취소선 + `ink-faint`. 각 카테고리 끝에 "할 일 추가" 점선 체크박스 행 — 누르면 그 자리에서 한 줄 입력, Enter로 저장, Esc로 취소. 카테고리가 없는 할 일(기존 데이터)은 "기타" 묶음 맨 아래.
     항목 길게 누르기/호버 시 ⋯ → 수정 · 카테고리 바꾸기 · 날짜 옮기기 · 삭제.
   - 오른쪽 세 섹션, 1px 선으로 구분:
     - **완료율**(선택한 날짜 기준, 제목은 오늘이면 "오늘 완료율", 아니면 "10/30 완료율"): 30px 숫자 "43 %" + 4px 직선 진행 막대(검정). 기존 `TodayGauge` 대체.
     - **오늘 일정**: 시간(12px muted) + 3px 세로 색 막대(종류 색) + 제목/장소. 기존 `TodaySchedule` 재스타일.
     - **마감 D-day**: 대학원 트래커에서 상태가 관심/준비 중인 학교의 마감 가까운 순 3개. "D-33", D-7 이내는 `danger` 색. 누르면 /grad 로. 학교가 없으면 "대학원 지원에서 학교를 추가해 보세요".
4. 지난 할 일 배너("지난 할 일 n개 · 오늘로 옮기기")는 머리 아래, 1px 테두리 상자로 유지.
5. 레벨업 토스트, 100% confetti 유지.

**카테고리 관리**: 할 일 제목 "오늘 할 일" 오른쪽 ⋯ → "카테고리 관리" 모달: 목록(이름, 색 네모 6개 중 선택, 순서 ↑↓, 삭제). 삭제 시 그 카테고리의 할 일은 카테고리 없음(기타)이 된다. 카테고리가 0개면 "기타" 묶음 하나와 추가 행만 보인다.
**기본 카테고리 시드**: 프로필 문서 로드 후 `categories`가 비어 있고 `profile.categoriesSeeded`가 true가 아니면 공부(sky) · 연구(mint) · 대학원(pink) 3개를 만들고 `categoriesSeeded: true`를 저장한다. 기존 사용자(프로필 이미 있음)도 이 규칙으로 받는다. 이후 사용자가 전부 지워도 다시 만들지 않는다.

### 5.2 학점
구조는 1단계와 같고 스타일만 바뀐다. 시안 기준:
- 머리: "학점" + 보조문 "2024-1 ~ 2026-1 · 6개 학기 · 포탈과 일치(또는 포탈과 0.02 차이)". 오른쪽 검정 버튼 "포탈 붙여넣기".
- **KPI 행**: 1px 테두리 상자 하나를 세로선으로 4칸 — 누적 평점 / 전공 평점 / 취득 학점 / 4.0 환산. 11px 라벨 + 22px 숫자 + 11px "/ 4.5" 같은 분모. 기존 `SummaryCards` 대체.
- 2열 (1.3fr : 0.7fr):
  - 왼쪽: 학기별 추이(Recharts 선 2개: 학기 평점 검정, 누적 `line-strong` 회색; 점은 검정; 격자 `line`; 그림자·면 없음) + 학기 목록(아코디언, 1px 선 구분, 행: 학기코드 700 · "6과목 · 18학점" muted · 평점 700). 펼치면 과목 행: 과목명 / 이수구분 / 학점 / 등급. 재수강 대체는 `ink-faint` + "재수강 대체" 작은 `danger` 글자.
  - 오른쪽: 졸업 요건 3개 (라벨 + "89 / 130" + 4px 직선 막대, 총학점은 검정, 전공 sky, 교양 mint) / 목표 시뮬레이터(목표 평점 pill 3개 4.2·4.3·4.4 + 직접 입력, 결과 문장).
- 포탈 붙여넣기 모달, 과목 추가/수정 폼: 기존 기능 그대로, 스타일만 §4.

### 5.3 시간표
기능 그대로. 주간 뷰 블록: 종류 색 `fill` 배경 + 왼쪽 3px `text` 색 선 + 4px 반경 + 검정 글자(흰 글자 금지 — 파스텔 위라 대비 부족). 월간 뷰: 날짜 칸 1px 격자, 일정은 점 + 제목. 종류 색 매핑: 수업 sky · 연구 mint · 일 butter · 기타 lilac.

### 5.4 대학원 지원 (`/grad`, 새 페이지)
**머리**: "대학원 지원" + 보조문 "6개 학교 · 가장 가까운 마감 D-33 (Stanford)". 오른쪽: Segmented "표 | 카드" (데스크톱만 보임) + 검정 버튼 "+ 학교 추가".

**필터 pill 행**: 전체 n · 관심 n · 준비 중 n · 제출 n · 결과 n. 하나만 선택. 기본 "전체".

**표 (데스크톱 기본)** 열, 왼쪽부터:
| 열 | 내용 |
|---|---|
| 학교 · 프로그램 | 학교명 700, 아래 11px muted로 프로그램 (예: Statistics PhD) |
| 마감 | "12/1" + "D-33" 700. D-7 이내 `danger`, 지난 마감 `ink-faint` "지남" |
| GRE | 태그: 필수(bad) / 선택(none) / 불요(none) |
| TOEFL | 최소 점수 숫자 + 태그 "충족"(ok) / "부족 (내 점수 82)"(bad) / "—"(최소 미입력 또는 내 점수 미입력) |
| 추천서 | "2 / 3" 태그: 다 채우면 ok, 아니면 warn |
| SOP | 태그: 미작성(bad) / 초안(warn) / 완료(ok) / —(불요) |
| 지원비 | 문자열 그대로 (예: $125, C$125) |
| 상태 | 작은 색 네모 + 글자: 관심(ink-faint) · 준비 중(butter) · 제출(mint) · 합격(sky) · 불합격(ink-faint) |

- 열 머리글 클릭으로 정렬 (마감·학교·상태). 기본 정렬: 마감 가까운 순, 지난 것은 맨 아래.
- 행 클릭 → 아래로 펼침: 메모(여러 줄), 링크 목록(제목+URL, 새 탭), 관심 교수 목록(이름 + 한 줄), "수정" · "삭제" 버튼.
- 표가 화면보다 넓으면 가로 스크롤(열 줄이지 않음). 열 폭은 `white-space: nowrap`.

**카드 (모바일 기본, 데스크톱 전환)**: 1px 테두리 4px 반경 카드 세로 나열. 머리: 학교명 700 + D-day(오른쪽). 아래 11px muted 프로그램 · 마감일. 행들(라벨 muted : 값/태그): GRE · TOEFL · 추천서 · SOP · 지원비 · 상태. 카드 탭 → 같은 펼침(메모·링크·교수) 모달.

**학교 추가/수정 모달** 필드: 학교명(필수) · 프로그램(필수, 학위까지 한 줄로 — placeholder "Statistics PhD") · 마감일(날짜, 필수) · GRE(필수/선택/불요, 기본 불요) · TOEFL 최소(숫자, 선택) · 추천서 필요 수(기본 3) · 추천서 확보 수(기본 0) · SOP(불요/미작성/초안/완료, 기본 미작성) · 지원비(문자열) · 상태(기본 관심) · 메모 · 링크(여러 개) · 관심 교수(여러 개). 삭제는 확인 후.

**내 점수**: 설정에 "내 TOEFL 점수"(숫자, 선택) 추가. 표의 충족/부족은 이 값과 비교. GRE 점수는 안 받음(요구 여부만 관리).

**홈 연동**: §5.1 마감 D-day 섹션.

### 5.5 설정 · 더보기 · 로그인
- 설정: 섹션 제목 12px 대문자 느낌 대신 14px 700, 섹션 사이 1px 선. "내 TOEFL 점수" 필드 추가(현재 학기 섹션 아래 "대학원" 섹션).
- 더보기(모바일 전용 페이지): 논문 · 연구 · 설정 링크 3줄. "마감 D-day", "대학원 지원" 플레이스홀더 제거(대학원은 탭바로 승격).
- 로그인 페이지: 흰 바탕, 앱 이름 22px, 한 줄 설명, 검정 "Google로 계속하기" 버튼. 캐릭터·일러스트 없음.

## 6. 데이터 모델 추가 (`users/{uid}/...`)

```
categories/{id}:  { name: string, color: 'sky'|'mint'|'pink'|'butter'|'lilac'|'peach', order: number }
todos/{id}:       기존 + categoryId: string | null     // 없거나 null → "기타"
schools/{id}: {
  name: string, program: string,            // program에 학위 포함 ("Statistics PhD")
  deadline: 'YYYY-MM-DD',
  gre: 'required'|'optional'|'none',
  toeflMin: number | null,
  recsRequired: number, recsDone: number,
  sop: 'none'|'todo'|'draft'|'done',
  fee: string,
  status: 'interested'|'preparing'|'submitted'|'accepted'|'rejected',
  notes: string,
  links: { title: string, url: string }[],
  professors: { name: string, note: string }[],
  createdAt: string
}
users/{uid}.profile: 기존 + toeflScore: number | null, categoriesSeeded: boolean
```
- 보안 규칙은 기존 패턴(자기 uid만) 그대로 두 컬렉션 추가.
- 내보내기/가져오기(`exportImport.ts`)에 `categories`, `schools` 포함. 예전 백업 파일(두 컬렉션 없음)도 읽혀야 한다.
- 기본 카테고리 시드 규칙은 §5.1.

## 7. 빌더에게 맡기는 것
- Tailwind 클래스 정리 방식(토큰 이름 유지 vs 전면 교체) — 토큰 이름 유지 권장.
- Recharts 스타일링 세부, 표 정렬 아이콘, 펼침 애니메이션(없어도 됨).
- 카테고리 색 선택 UI의 정확한 모양(6개 네모면 충분).
- 테스트: D-day 계산, TOEFL 충족 판정, 정렬 규칙, 카테고리 묶기(기타 처리), 내보내기/가져오기 호환은 단위 테스트. UI는 브라우저로 수동 확인.
- 영어 번역 문구.
- 시안에 쓴 샘플 데이터(Stanford 등)는 예시일 뿐, 시드하지 않는다.

## 8. 내가 정한 것 (사용자가 뒤집을 수 있음)
- 모바일 탭바에서 논문·연구를 더보기로 내리고 대학원을 올림. 지금 논문·연구는 플레이스홀더라 손해 없음.
- 홈 D-day 섹션은 **대학원 마감만** 보여줌. 일반 D-day(§6.7)는 다음 단계.
- GRE는 점수 없이 요구 여부만. TOEFL은 최소 점수 + 내 점수 비교.
- 카테고리 색 6개 고정 팔레트(자유 색상 선택 없음).
- 다크 모드는 유지하되 흑백 반전 수준. 따로 시안 안 만듦.
- 학교 상태 5개: 관심 · 준비 중 · 제출 · 합격 · 불합격.
- (빌더 검토 후 추가) 주간 띠는 ‹ › 로 다른 주로 넘어갈 수 있고, 선택한 날짜는 할 일·완료율만 바꾼다(일정·D-day는 오늘 고정).
- (빌더 검토 후 추가) 기본 카테고리는 기존 사용자도 받는다 (`categoriesSeeded` 플래그로 한 번만).
- (빌더 검토 후 추가) 학위 필드는 따로 두지 않고 프로그램 이름에 포함 ("Statistics PhD"). 입력이 하나 줄어든다.
