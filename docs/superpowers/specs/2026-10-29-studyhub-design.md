# StudyHub 설계 문서 (2026-10-29)

> 작업명은 임시로 "StudyHub"다. 사용자가 다른 이름을 정하면 전부 바꾼다.

## 1. 의도와 이유

고려대학교 통계학과 3학년 2학기 학부생(학부연구생 여러 개 병행, 북미 대학원 준비 중)이
노션 대신 쓸 **개인 학업·연구 관리 웹앱**. 노션은 자유도가 너무 높아서 어려웠다는 것이
출발점이므로, 이 앱의 최우선 가치는 **단순함**이다. 기능이 많아도 화면마다 "지금 할 수 있는
일"이 한두 개로 보여야 한다.

노트북 브라우저와 아이폰·아이패드에서 같은 데이터를 쓰고, 괜찮으면 친구에게도 소개할
수 있어야 한다. 나중에 기능을 추가해 달라고 하면 기존 데이터를 깨지 않고 바로 반영되는
구조여야 한다.

## 2. 사용자

- 1차 사용자: 본인. 성적 관리가 최우선, 그다음 논문/연구, 시간표, 할 일.
- 2차 사용자: 소개받은 친구들(같은 학교 학생일 가능성 높음). 각자 구글 로그인해서 자기
  데이터만 본다. 데이터 공유 기능은 없다.

## 3. 목표 / 비목표 / 안티목표

**목표**
- 포탈 성적표 두 개를 복붙하면 전 학기 과목·학점·평점이 자동 정리된다.
- 졸업까지 남은 학점, 학기별 평점 추이, 전공 GPA, 목표 학점 시뮬레이터가 한 화면에 있다.
- 논문을 연구 주제별로 모으고, DOI/arXiv 링크로 서지 자동 입력, 마크다운 요약(사진 포함)을
  쓸 수 있다.
- 주간 시간표와 월간 캘린더, 오늘 할 일과 동기부여 게이지(완료율 + 레벨/XP)가 있다.
- 연구 프로젝트별 칸반 + 미팅 노트, 과제/마감 D-day, 대학원 지원 트래커.
- 노트북 브라우저와 아이폰/아이패드(홈 화면 추가)에서 동일하게 동작, 데이터는 클라우드 동기화.
- 한국어 기본, 영어 전환 가능.
- 기능 추가/수정이 쉬운 구조. git push 한 번이면 모든 기기에 반영.

**비목표**
- 앱스토어 네이티브 앱. (PWA로 충분. 요청 시 나중에 Capacitor로 감쌀 수 있게 구조만 열어둔다.)
- Zotero 연동, PDF 전문 저장. (링크 + md 요약으로 대체)
- 사용자 간 공유/협업, 실시간 동시 편집.
- 포탈 자동 로그인/크롤링. (복붙만 지원)

**안티목표 (이러면 실패)**
- 노션처럼 "빈 페이지 + 블록"을 주고 사용자가 구조를 설계해야 하는 것.
- 설정 화면이 길어서 첫 사용 전에 10개 넘게 입력해야 하는 것.
- 폰에서 가로 스크롤이 생기거나 버튼이 손가락보다 작은 것.
- 기능 하나 추가하려고 기존 데이터 마이그레이션을 손으로 해야 하는 것.

## 4. 제약

- 비용: 무료 티어 안에서 동작 (Firebase Spark, Vercel Hobby).
- 사용자는 개발자가 아니다. 배포·설치 절차는 "명령어 한 줄 / 버튼 한 번" 수준으로 문서화.
- 개인정보(성적)가 들어가므로 Firestore 보안 규칙은 "본인 uid 문서만 읽기/쓰기".

## 6. 화면과 기능

내비게이션 탭 (순서 고정): **홈 · 학점 · 시간표 · 논문 · 연구 · 더보기**
"더보기" 안에: 마감 D-day, 대학원 지원, 설정.

### 6.1 홈
- 상단: 오늘 날짜, 인사말, 레벨 뱃지 + XP 바.
- **오늘 게이지**: 오늘 할 일 완료율 원형/막대 게이지. 100% 되면 짧은 애니메이션(confetti 수준).
- **오늘 할 일**: 체크 리스트. 출처 표시 칩(연구명 / 과목명 / 일반). 인라인 추가 입력칸 하나.
  - 할 일 출처: 일반 할 일, 연구 보드 칸반 카드 중 마감일이 오늘 이하인 것, 마감 D-day 항목 중 오늘인 것.
- **오늘 시간표**: 오늘 요일의 수업·고정 일정을 시간순 세로 리스트. 지금 진행 중인 항목 강조.
- 다른 건 넣지 않는다.

### 6.2 학점
**6.2.1 가져오기(복붙)**
- 버튼 "포탈에서 가져오기" → 모달에 큰 textarea 두 개: ① 학기별 성적, ② 과목별 성적.
  각각 포탈 화면에서 전체 선택 후 붙여넣기. 미리보기 표를 보여주고 "저장" 누르면 반영.
- 재가져오기 시 기존 과목은 학수번호+학기 기준으로 덮어쓰고, 수동 입력 과목은 보존.

**파서 사양** (실제 데이터로 검증됨)

① 학기별 성적: 줄 단위. `^\d{4}학년도 .+$` 에 매칭되는 줄이 학기 헤더, 뒤 6줄이 순서대로
신청학점, 취득학점, 총평점, 평균평점(증명용), 평균평점(전체), 환산점수.
학기 이름 예: `2024학년도 1학기`, `2024학년도 계절수업(여름)`, `2024학년도 계절수업(겨울)`.
내부 코드: `2024-1`, `2024-S`, `2024-2`, `2024-W`.

② 과목별 성적: 줄 단위, **빈 셀은 줄 자체가 생략됨** → 과목마다 줄 수가 8~10으로 다르다.
원래 열: 학수번호, 분반, 과목명, 이수구분, 교과영역, 과목유형, 학점, 점수, 등급, 평점.
- 과목 시작 감지: 학수번호 패턴 `^[A-Z]{3,4}\d{3}$` 또는 `^\d{1,3}$`(교환 과목) 다음 줄이
  분반 패턴 `^[0-9A-Z]{2}$`.
- 각 과목 블록은 다음 과목 시작 직전까지. 블록 끝에서 역방향으로 읽는다:
  마지막 줄 = 평점(숫자), 그 앞 = 등급(`A+|A|B+|B|C+|C|D+|D|F|P|NP|S|U`),
  그 앞이 숫자면 점수(없을 수 있음), 그 앞 = 학점(정수).
  분반 다음 줄 = 과목명. 그 다음 줄 = 이수구분(`교양|전공필수|전공선택|학문의기초|일반선택|교직|자유선택` 등 알려진 집합).
  그 사이 남는 0~2줄 = 교과영역/과목유형 (하나의 문자열로 합쳐 `area`에 저장).
- **학기 배정**: 과목은 포탈 출력 순서대로 학기순이다. ①의 학기 순서대로 "신청학점" 합이
  찰 때까지 과목을 넣는다. 실제 데이터로 18/3/22/3/15/18/12 전부 정확히 맞았다.
  합이 안 맞으면 경고를 띄우고, 남은 과목은 "미배정"으로 두고 사용자가 드래그/선택으로 옮긴다.
  ①에만 있고 ②에 과목이 없는 학기(성적 미입력 학기)는 과목 0개로 저장하고 경고하지 않는다.
- 등급 `P`, `S`는 평점 계산에서 제외(학점은 취득 학점에 포함). `NP`, `U`는 평점·취득 학점 모두 제외. `F`는 평점 0으로 포함.
- ①에서도 빈 셀이 생략될 수 있다고 가정하고, 헤더 다음 줄 수가 6 미만이면 앞에서부터 채우고 나머지는 null.
- 샘플 원문(두 표 전체)은 이 문서 끝 부록 A에 있다. 그대로 픽스처로 쓴다.

**재수강 규칙** (사용자가 재수강 가능성 있음)
- 같은 학수번호가 둘 이상이면 가장 최근 학기 것만 "유효". 이전 것은 `supersededBy` 필드를 달고
  표에서는 흐리게 + "재수강" 뱃지로 보이되, 누적 평점·이수 학점·전공 GPA·졸업 요건 계산 전부에서 제외.
- 학기 평점·학기 취득 학점은 ①의 값을 그대로 표시(포탈 기준). 누적 평점만 과목 합산으로 계산.
- 설정의 "포탈 누적 평점" 값이 있으면 큰 숫자 옆에 작게 "포탈: 4.21" 표시, 0.01 넘게 다르면 노란 경고.

**검증용 기대값** (샘플 데이터 기준)
- 2024-1: 평점 대상 17학점, 총평점 73.5, 평균 4.32
- 전체 누적(2025-2까지): 324 / 77 = 4.21
- 환산점수 = 100 − (4.5 − 평균) × 10 (4.32 → 98.2, 4.00 → 95.0)

**6.2.2 요약 화면**
- 맨 위 큰 숫자: 누적 평점 (4.5 만점) · 4.0 환산 · 전공 평점 · 이수 학점/졸업 학점.
- 졸업 요건 게이지 3개: 전공 / 교양 / 총학점. 필요 학점은 설정에서 입력(기본값: 총 130,
  전공 ~, 교양 ~ 는 빌더가 고려대 통계학과 기준으로 조사해 placeholder로 넣고 "설정에서 확인하세요" 표시).
  전공 = 이수구분 `전공필수|전공선택`, 교양 = `교양|학문의기초`, 나머지는 총학점에만 포함.
- 학기별 평점 추이 선 그래프 (학기 평점 + 누적 평점 두 선). 계절학기도 점으로 포함.
- 학기 아코디언: 펼치면 과목 표 (과목명, 이수구분, 학점, 등급, 평점). 행 클릭하면 수정 가능.
- "과목 직접 추가" 버튼 (포탈에 아직 없는 과목용).

**6.2.3 목표 학점 시뮬레이터**
- 입력: 목표 누적 평점, 남은 학점 수(자동: 졸업 학점 − 이수 학점, 수정 가능).
- 출력: "남은 N학점을 평균 X.XX 이상 받아야 함". 불가능(>4.5)이면 빨갛게 표시.
- 이번 학기 과목에 예상 등급을 넣으면 "이번 학기 후 누적 평점" 미리보기.

**6.2.4 이번 학기 (진행 중 과목)**
- 과목 추가: 과목명, 학점, 이수구분. (시간표 복붙에서 자동 생성되는 과목과 연결)
- 과목 안에 평가 항목: 이름(중간/기말/과제1…), 반영 비율(%), 내 점수, 만점. 미입력은 비움.
- 현재 가중 점수와, 비율 합이 100이 안 되면 "남은 비율 X%" 표시.
- 학기가 끝나면 "성적 확정" 버튼으로 등급 입력 → 6.2.2로 이동. 포탈 재가져오기 하면 덮어씀.

### 6.3 시간표
- **주간 보기**: 월~금(토·일 토글) 세로 시간축 09:00~21:00 (범위 자동 확장). 각 항목은 색 블록.
  종류: 수업 / 연구·미팅 / 과외·알바 / 기타. 종류별 파스텔 색.
- **월간 보기**: 달력. 날짜 셀에 마감 D-day 항목과 일회성 일정 점 표시. 날짜 탭하면 그날 목록.
- 항목 추가: 제목, 종류, 요일(복수 가능), 시작/종료 시간, 장소, 반복 여부(매주 / 특정 날짜 한 번),
  적용 기간(학기 시작~종료, 기본값 설정의 현재 학기 기간).
- 포탈 시간표 복붙: 형식은 아직 모름. **빌더는 "텍스트 붙여넣기 → 미리보기 → 저장" 틀과
  파서 교체 지점(`parseTimetable(text)`)만 만들고, 수동 입력을 완성한다.** 형식은 사용자가
  나중에 줄 때 파서만 채운다.
- 학기 정보: 설정에 현재 학기 코드와 시작/종료일.

### 6.4 할 일 · 게이지 · XP
- 할 일 필드: 제목, 날짜(기본 오늘), 출처(일반/연구 프로젝트/과목), 완료 여부, 완료 시각.
- 반복 할 일 없음 (단순함 우선). 지난 미완료 할 일은 홈 상단에 "어제 못 한 것 N개 → 오늘로 옮기기" 한 줄.
- XP: 할 일 완료 +10, 연구 칸반 카드 완료 +20, 논문 읽기 상태 "다 읽음" +30, 과목 평가 점수 입력 +5.
  체크 해제하면 회수. 레벨 = floor(sqrt(XP / 50)) + 1. 레벨업 시 홈에 토스트.
- 오늘 완료율 = 오늘 날짜 할 일 중 완료 비율. 할 일 0개면 게이지 비우고 "오늘 할 일을 추가해 보세요".

### 6.5 논문
- 좌측(데스크톱)/상단 칩(모바일): 주제 폴더 목록 + "전체". 폴더 추가/이름 변경/색.
- 논문 카드: 제목, 저자(첫 저자 외 N명), 연도, 학술지/학회, 읽기 상태 뱃지, 별점, 태그 칩, 한 줄 요약.
- 추가 흐름: 모달에 입력칸 하나 "DOI, arXiv 링크, 또는 제목". 
  - DOI → Crossref `https://api.crossref.org/works/{doi}` 
  - arXiv → `https://export.arxiv.org/api/query?id_list={id}` 
  - 성공 시 제목·저자·연도·출처·URL 자동 채움, 실패 시 빈 폼. 폼은 제목/저자/연도/출처/URL/주제(복수)/태그.
- 상세 화면: 메타 정보 + 읽기 상태(안 읽음/읽는 중/다 읽음) + 별점 + 한 줄 요약 + **요약 노트**.
  요약 노트 = 마크다운. 편집/미리보기 토글. `.md` 파일 업로드 버튼(내용을 노트에 넣음).
  이미지: 편집창에 **붙여넣기(Ctrl+V / 아이폰 길게 눌러 붙여넣기)** 하거나 이미지 버튼으로 선택 →
  브라우저에서 압축 → Firestore `images` 문서로 저장 → 커서 위치에 `![](img:{id})` 삽입.
  미리보기에서 `img:{id}`를 data URL로 치환. 노트 다운로드(.md) 버튼(이미지는 data URL로 인라인).
- 필터: 주제, 태그, 읽기 상태, 별점. 검색: 제목/저자.
- BibTeX 내보내기는 비목표였으나 Crossref 응답에 다 있으므로 **논문 상세에 "BibTeX 복사" 버튼 하나**만 넣는다 (내 결정, 비용 거의 0).

### 6.6 연구 프로젝트 보드
- 프로젝트 목록 카드: 이름, 지도교수/소속(자유 텍스트), 색, 진행 중/완료.
- 프로젝트 상세:
  - **칸반**: 할 일 / 진행 중 / 완료 세 칸. 카드: 제목, 마감일(선택), 메모. 드래그 또는 버튼으로 이동.
    마감일이 오늘 이하인 "할 일/진행 중" 카드는 홈 오늘 할 일에 자동 등장.
  - **미팅 노트**: 날짜순 리스트. 항목: 날짜, 제목, 마크다운 본문, "다음까지 할 것" 체크리스트
    (체크 항목은 칸반 "할 일"로 보내기 버튼).
  - **연결된 논문**: 이 프로젝트에 연결된 논문 칩 (논문 쪽에서 프로젝트 선택).

### 6.7 마감 D-day (더보기)
- 항목: 제목, 날짜, 종류(과제/시험/논문 제출/지원 마감/기타), 연결 과목 또는 프로젝트(선택), 완료.
- 리스트: 가까운 순, D-3 이내는 강조색. 지난 것은 접힘.
- 월간 캘린더와 홈 오늘 할 일에 반영.

### 6.8 대학원 지원 트래커 (더보기)
- 학교 카드: 학교, 프로그램(예: Statistics PhD), 국가, 마감일, 상태(관심/준비 중/제출/결과), 메모.
- 공통 체크리스트(한 번만 관리): SOP, CV, 추천서 1·2·3, TOEFL/IELTS, GRE, 성적증명서, 기타 추가.
  각 항목 완료 체크. 학교 카드에는 "이 학교에 추가로 필요한 것" 자유 체크리스트.
- 관심 교수 메모: 학교 카드 안에 이름 + 한 줄.

### 6.9 설정 (더보기)
- 프로필(구글에서 가져온 이름/사진), 언어(한/영), 테마(라이트/다크 자동).
- 현재 학기 코드와 기간, 졸업 요건 학점 3개, 4.0 환산표.
- 데이터 전체 JSON 내보내기 / 가져오기 (백업 + 나중에 구조 바꿀 때 안전망).
- 로그아웃.

## 8. 확장성 원칙

- `src/features/<모듈>/` 폴더 하나 = 기능 하나 (화면, 훅, 타입, i18n 키). 새 기능 = 새 폴더 + 내비 한 줄.
- Firestore는 스키마 없는 문서라 필드 추가는 마이그레이션 없이 된다. 필드 이름 변경은 피하고,
  필요하면 읽을 때 기본값을 넣는 `normalize*()` 함수를 모듈마다 둔다.
- 포탈 파서들은 `src/lib/parsers/`에 순수 함수로 두고 샘플 텍스트로 단위 테스트를 붙인다.
  포탈 형식이 바뀌면 그 파일만 고친다.
- 배포: `git push` → Vercel 자동 빌드. 사용자가 할 일은 Claude에게 말하기 → 커밋/푸시.

## 9. 디자인 방향

- 따뜻한 파스텔: 크림색 배경, 살구/연보라/민트/연노랑 포인트. 둥근 모서리(16px), 부드러운 그림자.
- 글꼴: Pretendard(한글) + 숫자는 탭형 숫자. 
- 동기부여 요소: 게이지, 레벨 뱃지, 레벨업 토스트, 100% 달성 confetti. 과하지 않게.
- 모바일 우선 레이아웃. 하단 탭 5개 + 더보기. 데스크톱은 좌측 사이드바로 같은 메뉴.
- 다크 모드는 시스템 설정 따라감 (파스텔 톤 유지한 어두운 변형).
- 구현 시 `ui-ux-pro-max` 스킬로 팔레트·폰트 확정.

## 10. 단계

1. **코어**: 프로젝트 셋업, 구글 로그인, 설정, 학점 모듈 전체(파서 포함), 할 일 + 홈 게이지/XP, 시간표 수동 입력 + 월간 캘린더. 배포 + PWA. → 이 시점에 사용 시작 가능.
2. **연구**: 논문(주제/태그/DOI/md 노트/이미지), 연구 보드(칸반/미팅 노트).
3. **더보기**: 마감 D-day, 대학원 지원 트래커, 이번 학기 과목 점수.
4. **마무리**: 영어 번역 채우기, 아이폰/아이패드 설치 안내 문서, 백업 내보내기/가져오기.

## 11. 빌더에게 맡기는 것

- 정확한 색상 값, 아이콘 세트, 애니메이션 세부.
- Firestore 인덱스, 쿼리 구조, 오프라인 캐시 세부.
- 포탈 시간표 파서 (형식 미정 → 교체 지점만).
- 고려대 통계학과 졸업 요건 기본값 조사 (못 찾으면 총 130 / 전공 0 / 교양 0 으로 두고 설정 안내).
- 테스트 범위: 파서와 학점 계산은 단위 테스트 필수, UI는 수동 확인.
- 영어 번역 문구.

## 12. 초기 세팅 역할 분담 (1단계 시작 시)
