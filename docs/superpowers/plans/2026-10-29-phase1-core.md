# StudyHub Phase 1 (코어) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 구글 로그인 + 포탈 복붙 학점 관리 + 할 일/게이지/XP + 시간표/월간 캘린더 + 설정을 갖춘 PWA를 Vercel에 배포해 노트북과 아이폰/아이패드에서 쓰기 시작할 수 있게 한다.

**Architecture:** Vite+React+TS 단일 페이지 앱. 모든 데이터는 Firestore `users/{uid}/...` 아래, 실시간 구독 + 오프라인 캐시. 순수 로직(파서, 학점 계산, XP, 날짜)은 `src/lib/`에 두고 vitest로 테스트. 기능별 폴더 `src/features/<모듈>/`.

**Tech Stack:** Vite 7, React 19, TypeScript, Tailwind CSS v4, react-router v7, Firebase JS SDK v11 (Auth, Firestore), Recharts, vite-plugin-pwa, vitest, Pretendard 폰트(CDN).

**Spec:** `docs/superpowers/specs/2026-10-29-studyhub-design.md` (이하 "스펙")

## Global Constraints

- 무료 티어만: Firebase Spark, Vercel Hobby. Firebase Storage 사용 금지.
- Firestore 보안 규칙: `request.auth.uid == uid` 인 `users/{uid}/**` 만 읽기/쓰기.
- 모바일 우선. 폰 폭(375px)에서 가로 스크롤 금지, 탭 가능한 요소 최소 44px.
- 모든 사용자 노출 문자열은 `src/i18n/ko.json`, `en.json` 키를 통해. 하드코딩 금지. (영어 값은 이 단계에선 한국어와 같아도 됨)
- 기본 프로필 값: `lang:'ko'`, `currentTerm:'2026-2'`, `termStart:'2026-09-01'`, `termEnd:'2026-12-20'`, `gradReq:{total:130, major:0, liberal:0}`, `xp:0`, `appName:'StudyHub'`, `gpaPortal:null`.
- 4.0 환산표 기본값: `A+:4.0, A:3.7, B+:3.3, B:3.0, C+:2.3, C:2.0, D+:1.3, D:1.0, F:0`.
- XP: 할 일 완료 +10 (체크 해제 시 회수). 레벨 = `floor(sqrt(xp/50)) + 1`.
- 환산점수 = `100 - (4.5 - gpa) * 10`, 소수 1자리.
- 등급 집합: `A+ A B+ B C+ C D+ D F P NP S U`. 평점 제외: P S NP U. 취득 학점 제외: F NP U.
- 전공 = 이수구분 `전공필수|전공선택`, 교양 = `교양|학문의기초`.
- 학기 코드: `YYYY-1`, `YYYY-S`(여름), `YYYY-2`, `YYYY-W`(겨울). 정렬 order = `year*10 + {1:1,S:2,2:3,W:4}`.
- 커밋은 태스크마다. 메시지는 영어 conventional commits.
- UI 색/폰트 확정 전에 `ui-ux-pro-max:ui-ux-pro-max` 스킬 호출 (Task 2).
